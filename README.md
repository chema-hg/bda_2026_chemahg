# practicas_bda

Este repositorio contiene las prácticas realizadas a lo largo del módulo **Big Data Aplicado**, dentro de la Especialización en Inteligencia Artificial y Big Data.

Las prácticas están organizadas por unidades de trabajo (UT), y cada una incluye los ejercicios correspondientes en formato Markdown.
