# PR0101. Preparación del repositorio de entrega de prácticas

**Módulo:** Big Data Aplicado
**Unidad de Trabajo:** UT01. Paradigmas distribuidos

## Objetivo

Preparar el repositorio en GitHub que se utilizará para entregar las prácticas a lo largo del curso.

## Desarrollo

Se ha creado un directorio local llamado `practicas_bda`, inicializado como repositorio Git y estructurado en carpetas por unidad de trabajo, cada una con sus correspondientes prácticas en formato Markdown.

El repositorio se ha vinculado con un repositorio remoto en GitHub llamado `bda_2026_jmhg`, y se ha publicado mediante GitHub Pages.

- **URL de la página publicada en GitHub Pages:** [https://chema-hg.github.io/bda_2026_jmhg/](https://chema-hg.github.io/bda_2026_jmhg/)
